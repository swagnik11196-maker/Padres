# Padres

Verified friends, dating and threads app for every adult 18+, with an optional Parents section and a built-in SOS safety center. Bangladesh first, then the UK.

**Live demo:** open `index.html`, or visit the GitHub Pages link for this repository.

This is an interactive prototype: sample people and chats, nothing is sent, called or charged. Progress is saved only in each visitor's own browser.

## Install on a phone
- iPhone: open the link in Safari → Share → Add to Home Screen
- Android: open in Chrome → ⋮ → Add to Home screen / Install app
